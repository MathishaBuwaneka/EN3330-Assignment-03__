## Important mathematical distinction

The exact primal function in Q1(c) has an infinite value when $x<1$; the finite plotted curves approximate it by bounding the Lagrange multiplier, **not** by claiming that infinity is a finite plot value. In Q3(b), the three-line *lower envelope* lies **above** the exact dual (because only three $x$ values are tested); both are concave.
